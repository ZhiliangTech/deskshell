## 三条纪律

1. **一人一稿**：开场句必须提到对方仓库里的具体实现，禁止群发。
2. **先给价值**：在别人仓库只做技术评论，不谈项目，除非对方问。
3. **两次跟进就停**：5 天、12 天，然后不再发；把精力换到下一个人。

## 每天 30 分钟的固定动作

```
1. 打开 TARGETS.md，取 5 个 A/B 档
2. 各写一段 25 字以内的定制开场，发出去
3. 更新 TRACKER.csv（日期 + 渠道）
4. 回复所有回信（48 小时 SLA）
5. 有回复的，把对应 GOOD-FIRST-ISSUES 条目链接发过去
```
