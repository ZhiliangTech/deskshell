# AMBITION — 如果目标是"下一个 OpenClaw"

> 这份文件只回答一个问题：**要做成跨时代的东西，缺的到底是什么。**
> 不是鸡血，是把"跨时代"拆成可以验证的几件事。

## 0. 先把参照物说准

OpenClaw 是**一个助手**：装在你自己机器上、能替你干活的 agent。它破圈靠三件事——一条命令装好、一个"它真的动了我的电脑"的瞬间、一个插件生态。

我们要做的不是第二个助手。我们要做的是**助手动你电脑时底下那层**：动作有合同（声明 / 断言 / 撤销 / 审计）。

这两件事不冲突，而且顺序很清楚：**助手负责"想干什么"，我们负责"干成了没有、能不能退回去"。** 想当"下一个 OpenClaw"级别的项目，不必去和它抢"助手"这个位置，而是成为所有助手默认的那层——包括它。

## 1. "跨时代"必须落成一句普通人能复述的话

技术叙事（对内）：OS runtime for agents，每个动作是一份可断言、可撤销、可审计的合同。

**大众叙事（对外，只需要这一句）：**

> **AI 弄坏的东西，一句话退回去。**

这是唯一一个不需要解释协议、不需要懂 agent 的人也能立刻理解的差异点。OpenClaw 让人相信"AI 能替你干活"；我们要让人相信"AI 干活出事了，能收场"。前者是能力，后者是信任——**信任才是这一代的稀缺品**。

## 2. 跨时代的三根支柱（缺一根就只是个好库）

| 支柱 | 现在有什么 | 缺什么 | 怎么补 |
| --- | --- | --- | --- |
| **可感知的瞬间** | `story --fail` 能演示失败回滚 | 没有 30 秒、不用读文档就能看懂的版本 | 录一条：三个操作 → 第四步失败 → 全部退回 → 日志逐行出现。放在 README 第一屏 |
| **可复现的证明** | 43 项回归、13 项驱动契约 | 没有**对外指标**。别人凭什么信你比"会点鼠标"强 | 定义并发布一个指标：**R0 = 失败后副作用归零率**，附脚本，任何人都能跑 |
| **可接入的接口** | 协议 v0 冻结、驱动契约 | 没有让别的 agent 调你的入口 | **MCP adapter（GFI-09）**：三个 tool，任何 MCP 客户端能调。这是"成为默认那层"的唯一路径 |

## 3. 指标：把"跨时代"变成一个数

`R0（recovery rate at zero residue）`：给定 N 个任务、注入 M 种失败，统计

- 失败后**副作用完全归零**的比例；
- 日志里**每一步都能追溯到**的比例；
- 撤销后**逐字节还原**的比例。

为什么这个指标重要：所有 computer-use 项目都在比"成功率"，没人比"失败之后留下了什么"。**定义一个别人不测的维度，比在别人的维度上追分更快成为标准。**

落地成本很低：`scripts/regress.ts` 里已有 `--fail-at` 类基座与 43 条断言，把它抽成 `scripts/recovery-bench.ts`，输出一张表即可。

## 4. 90 天：从"好库"到"默认那层"

| 阶段 | 动作 | 判据 |
| --- | --- | --- |
| D1–14 | 30 秒 demo + R0 脚本 + MCP adapter | 三条链接能直接放进任何对话 |
| D15–45 | 把 MCP adapter 推给 3 个 agent 运行时（e2b / daytona / trycua） | 至少 1 个愿意在自己的文档里提一句 |
| D46–90 | 用 R0 发一篇对照文章：拿 3 个主流方案跑同一组失败注入，只报数不评价 | 有人引用这张表，或有人来质疑它 |

## 5. 诚实的差距（不写清楚就是自欺）

- **分发**：OpenClaw 级项目靠的是"装完就能用"。我们现在连 `npm i -g deskshell` 都还没通（卡在 2FA 审批）。这是第一优先，不是细节。
- **一个用户能讲的故事**：现在所有文案都在讲机制，没有一句能被转发。
- **一个外部贡献者**：0。没有第一张外部 PR，"生态"只是我们自己说的。

## 6. 三件不要做

1. **不要去做助手**。那是 OpenClaw 的战场，我们去做只会变成"又一个"。
2. **不要在宣传里用"跨时代/颠覆"**。这两个词会让人立刻关页面；用 R0 这张表说话。
3. **不要为了显得大而加功能**。跨时代来自"少而不可替代"，不是"多"。
