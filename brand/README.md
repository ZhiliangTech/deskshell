## Setting the GitHub social preview

GitHub has no API for this; it must be uploaded once:

1. Open `https://github.com/ZhiliangTech/deskshell/settings`
2. Scroll to **Social preview** → **Edit** → **Upload an image**
3. Choose `brand/social-preview.png` (1280×640, under 1 MB)

## Regenerating the PNG

The PNG is a headless-Chrome render of the SVG, so it stays crisp:

```bash
chrome --headless=new --disable-gpu --hide-scrollbars \
  --window-size=1280,640 \
  --screenshot="brand/social-preview.png" \
  "file://$(pwd)/brand/social-preview.svg"
```

On Windows the Chrome binary lives at
`C:\Program Files\Google\Chrome\Application\chrome.exe`, and the file URL needs
forward slashes: `file:///F:/.../brand/social-preview.svg`.

Terminal screenshots and the animated demo live in `docs/assets/` and are generated by
`scripts/make-assets.py`.
