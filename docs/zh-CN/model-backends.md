# 云端模型接入与未来本地模型适配

更新日期：2026-10-31。DeepSeek 受限提案适配器、Windows 凭据入口和固定授权多轮协调器已实现。除合成照片的真实提案/批准/执行链路外，真实 DeepSeek 与合成编辑器已完成三轮观察、阶段选择、执行及目标验证。固定原生记事本计划另已通过完整服务链，CRLF/LF 两次成功；本地合成规划与真实 DeepSeek 加原生三轮、四类真机故障及默认生产服务均已通过，精确配置已放行。追问界面、自由任务规划及完整 G3 仍未完成。

当前采用国产云端大模型 API 验证智能体系统，未来接入本地模型。任务宿主、资源视图、授权、执行、日志和恢复运行在用户电脑上；模型通过受限提案接口参与规划。长期本地模型方向不要求当前原型先具备本地推理硬件。

## 首个云端适配目标

选择 DeepSeek 官方 API 的 `deepseek-flash` 作为首个工程默认。它的官方文档列有 JSON 输出、工具调用及按 token 计费，足够支持首轮受限技能规划实验。这是起步选型，不是本项目任务集上的性能排名。[模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)

| 项目 | 当前设计 |
| --- | --- |
| 供应商 | DeepSeek 官方服务，直接接入；不隐式切换第三方转售端点 |
| API | HTTPS Chat Completions，端点 `https://api.deepseek.com/chat/completions` |
| 请求模型 | 当前适配器仅接受 `deepseek-flash`；更换模型需同步能力、费率与契约测试 |
| 版本记录 | 2026-10-31 官方页面将该别名对应到 `DeepSeek-V4.1-Flash-1017`；实验同时记录请求名、返回标识和时间，不将可变别名当作永久固定快照 |
| 初始模式 | 显式使用非思考模式，作为成本与结构化提案基线；思考模式另作配置与对照 |
| 初始交互 | 暴露受限的技能提案工具；返回值经宿主校验后进入 prepare，不直接调用系统驱动 |
| 传输实现 | 已使用 Node fetch，供应商协议封装在 `packages/models/src/deepseek.ts`，没有新增 SDK 依赖 |
| 凭据 | Windows DPAPI CurrentUser 加密保存于仓库外的私有目录，宿主通过内部管道读取；密钥不进入参数、环境变量、计划或日志 |
| 费用 | Backend 有实例请求数与估算费用上限：照片单计划 1 请求/0.01 USD，多轮会话按剩余轮数/0.05 USD；服务另共享全用户 UTC 日预算，默认 10 请求/0.10 USD |

官方[工具调用文档](https://api-docs.deepseek.com/guides/tool_calls)给出了非思考模式工具调用，strict schema 属于 Beta 接口。第一版不依赖 Beta 才能保证参数校验；tool call 的名称、参数、资源与版本始终在宿主验证。未知工具、多个不受支持的提案、额外字段或过期观察都不能直接执行。

[JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)说明 JSON 模式仍可能出现空白内容或被长度限制截断。因此“返回 JSON”不等于符合业务 schema，更不等于取得权限。适配器必须区分有效提案、无效结构、拒绝、空白、截断、超时和供应商错误。

[思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode)包含额外会话字段与参数约束。后续若启用，由供应商适配器维护必要的短期传输状态；模型内部推理不写入产品审计日志，也不作为批准或完成证据。

## 费用核对与预算

以下是 2026-10-31 官方价格页的 Flash 标价快照，单位为美元 / 百万 token，仅用于预算设计；实际调用前重新核对账户计费币种和现行价格。[官方计费说明](https://api-docs.deepseek.com/quick_start/pricing/)

| 项目 | 非高峰 | 高峰 |
| --- | --- | --- |
| 输入，未命中缓存 | 0.15 | 0.30 |
| 输出 | 0.60 | 1.20 |

预算按当时适用的保守费率估算，不能把未来缓存命中当作保证。每次发出请求前计入已用量、并发预留与该请求的最大输出估计；重试也占用预算。已发出的请求可能继续计费，取消和网络中断都不保证退回费用；usage 缺失时标为未知并保留估计，不能记为零。

适配器要求显式传入模型请求数、输入/输出上限、超时和估算费用上限。新 `agent` 服务还接入 SQLite 持久预算，发请求前在事务中原子预留请求数和费用，多个宿主不能各自把同一余额花掉。默认 UTC 日额度为 10 次、0.10 USD；Windows 默认账本位于 `%LOCALAPPDATA%\deskshell\model-budget`，跨任务状态目录共享，不因重启重置。该估算仍不是供应商账单保证。

在宿主运行时，`npm run agent -- budget --state <状态目录>` 查看日额度与记录；`budget-set --state <状态目录> --requests 10 --usd 0.10` 通过控制通道显式更新额度，不清除当天消耗。请求失败、取消、崩溃和 usage 未知都保留预留；可用信息只用于真实用量记账，不把未知当作零。当前不自动重试，模型不能修改额度。多轮会话另有固定轮数、能力、资源、输出和总时限，拒绝的提案也计入轮数与已用请求。

| 当前生产路径 | 请求与文本限额 | 整体边界 |
| --- | --- | --- |
| 照片单计划 | 1 请求，8,192 输入字节，512 输出 token，30 秒 | 0.01 USD 估算 |
| 记事本固定授权会话 | 默认 6 轮，可设 3–10 轮；每请求 16,384 输入字节，512 输出 token，30 秒 | 5 分钟；后端实例 0.05 USD 估算，请求数不得超过剩余轮数 |
| 同用户所有 agent 宿主 | 默认 UTC 日 10 请求 | 0.10 USD 估算，跨状态目录和重启共享 |

直接构造一个未接入账本的 `DeepSeekBackend` 只有实例内限额；早期 greeting demo 属于这一开发演示路径。全用户日预算承诺适用于新的常驻 `agent` 服务默认路径，不宣称能限制其他程序或同账户恶意代码自行调用 API。

## 本机配置与连接验证

在 Windows 仓库根目录运行以下入口。导入前将自己的 DeepSeek API key 复制到当前剪贴板，不把它粘贴进命令参数或项目文件：

```powershell
npm run model:configure -- --from-clipboard
npm run model:configure -- --status
npm run model:test
npm run runtime:cloud-demo -- --live
```

配置入口使用 Windows DPAPI CurrentUser，把密文保存在 `%LOCALAPPDATA%\deskshell\secrets\deepseek.v1.dpapi`，目录和文件采用当前账户私有 DACL。状态命令只输出配置状态和位置，不显示密钥；文件存在只说明已配置，实际可用性由连接验证确认。导入完成后仅在当前剪贴板仍匹配该 key 时清空它，不声称已清除系统剪贴板历史。

`model:test` 运行不读凭据、不联网的 17 组契约检查。`runtime:cloud-demo` 只有带 `--live` 才读取凭据并发出一次付费请求：最多 8,192 输入字节、256 输出 token、30 秒、0.01 USD 估算上限，无重试。它只发送固定合成文本和技能 schema；本机路径、用户文件内容和截图不进入请求。每次运行建立新的临时目录，保存 `evidence.json` 和待批准计划，不签发批准，不执行创建文件。

2026-10-31 15:23（Asia/Shanghai）的真实请求返回 `deepseek-flash`，输入 584 token、输出 194 token、总计 778 token；保守费用预留为 0.0008271 USD，不能当作实际账单。请求 ID 为 `41912f90-f42e-498e-86b8-60edc3a9bec2`。返回提案经本地 schema 检查后进入 `TaskHost.prepare`，任务停在 `awaiting_approval`，目标文件未创建。目标条件由可信代码固定，模型返回的 `goalCriteria` 不定义验收标准。

这证明凭据、官方 API、提案校验与固定计划预览链路可用；它不是照片整理、记事本操作或 G3 智能体闭环的验收结果。

随后新增的 `npm run agent -- plan ... --cloud [--deduplicate]` 接收自然语言目标，由常驻宿主准备受限照片整理或去重待确认计划；`inspect`、精确 `apply`、`status/cancel` 与恢复命令使用本地任务记录。照片单计划额度为 1 次请求、8,192 输入字节、512 输出 token、30 秒、0.01 USD 估算，并受上述持久日额度约束。它发送输入的目标和固定技能 schema，不自动发送本地目录、文件名、hash 或正文；用户主动写入目标的内容会随文本发送。先审阅再单独批准，完整命令见[文件任务](agent-file-task.md)。

2026-10-31 15:39 的照片任务真实请求为 `a1ad0e54-eac3-47a9-8175-518e22131699`，输入 673、输出 189、总计 862 token，保守费用预留 0.0012414 USD（非实际账单）。隔离合成夹具的 2 次建目录与 3 次移动，经独立 `apply` 后返回 `succeeded` 和目标满足，跨进程状态读取通过。该证据只覆盖根层照片按修改月份整理，仍不覆盖去重、撤销、真实用户照片库或记事本操作。

15:54 的版本验证使用真实请求 `a32ccbaa-cc9f-4308-ba64-080734d7304c`，输入 760、输出 405、总计 1,165 token，保守预留 0.0013473 USD。合成照片的按月/去重待确认计划经过单独批准执行，7 步后目标满足；随后单独批准 7 步恢复并核对原始完整快照相等。真实宿主停止/重启后，任务和用户级日预算的请求数、预留费用均保持；这次新增仅 1 次 API 请求，恢复不消耗模型请求。真实用户照片库、记事本和研究收益仍未据此验收。

以上 greeting 和照片用量是历史验证记录。同日应用版本新增真实 DeepSeek 与合成编辑器联调：三轮分别使用 889、912、895 token，合计 2,696 token、3 次请求，保守估算 0.0038343 USD（非账单）。模型依次选择 `open/edit/save-copy`，源文本保持，副本精确匹配，完整会话通过独立目标核验。该证据证明真实云模型参与多轮合同，不是原生记事本 UIA 验收。

固定原生计划的两次成功没有模型请求；早期两次本地合成规划尝试因 `GUARD_INPUT_CHANGED` 停止，保留为拒绝记录。后续本地合成规划加原生三轮成功，真实 DeepSeek 加原生又以 3 次请求完成完整服务链：843/890/810 token，合计 2,543，估算费用分别 0.0012618/0.0012834/0.0012864 USD，合计 0.0038316 USD（非账单）。三个模型轮次及原生阶段均 verified，源文保持、精确副本且仅新增预期文件。本应用版本两批真实三轮合计 6 次 API 请求、估算 0.0076659 USD；这不是 UTC 日计数，日账本还可能包含其他任务。

`session-plan --cloud` 只准备会话，`session-run` 在精确摘要批准后才开始多轮请求。外发内容为用户 intent、脱敏阶段观察、上轮阶段反馈和固定技能 schema；不自动发送正文、路径、文件名、hash 或窗口标识。用户主动写入 intent 的内容会随之发送。生产已放行精确 `11.2607.14.0/zh-CN` 配置，服务拒绝不匹配环境，原生限 UTF-8 无 BOM。每个生产宿主生命周期只执行一个文档任务，第二任务在新模型请求或 UI 输入前拒绝，须停止/重启并准备新计划。用法与限制见[多轮任务](autonomous-tasks.md)及[首个应用](first-application.md)。

## 模型可替换的契约

规划模块提交用户目标、经裁剪且允许发送的 TaskView、技能 schema、预算和取消信号。适配器返回规范化的提案、结束原因、调用标识与用量。供应商专有参数、流式消息和错误映射留在适配器中。

提案仍是 RFC 0001 的 `skillId + version + args + goalCriteria` 候选，后续可承接 RFC 0002 的资源/版本操作提案。宿主负责所有授权与执行认领。云端服务返回工具调用不会在本机自动执行，供应商托管的文件、浏览器、搜索和代码执行工具不进入首个适配器。

provider、endpoint、model、能力清单与价格配置由可信设置管理，模型和被读取文件不能修改。端点切换同时重新检查凭据适用范围、数据策略和能力；HTTP 重定向不得把认证信息发送到未经配置的其他主机。兼容 API 的供应商也需独立契约测试。

## 云端上下文与本地资源

本地读取权限和云端外发范围分别登记。外发范围绑定供应商、资源、数据类别与大小：文件名和元数据、正文片段、控件文本、截图分别处理。宿主在发送前核验实际 payload，不能把整个目录、完整桌面或后台窗口默认上传。

凭据、授权记录、恢复原始材料和未获准的内容不作为模型观察发送。请求审计保存必要的字段清单、范围、字节数、摘要及用途，不重复记录密钥或敏感原文。服务账户的数据留存与处理设置在接入时核对；使用国产服务仍属于云端传输。

对照实验先使用合成夹具和可发送的测试内容。未来本地后端也按真实端点与传输模式显示状态，不能凭“本地兼容 API”名称判断数据没有外发。

## 断网、重试与取消

当前多轮协调器持久绑定会话摘要、每轮索引、requestId、受限提案、效果和后续验证；记事本适配器将会话绑定到固定 taskId/planId。适配器的超时和取消覆盖响应正文读取，响应大小按实际字节核验，晚到响应被拒绝；鉴权、限流和传输错误只返回去敏错误码。取消、任务更新或预算耗尽后，晚到响应不得继续触发执行。未来推理重试只产生新候选；同一固定计划的持久执行认领仍保证不重复执行。

断网或服务不可用时停止需要新推理的步骤，显示原因；本地历史、停止任务和已具备证据的恢复继续可用。已批准的确定性批次按既定任务策略收尾，不伪造新的模型判断。鉴权失败、限流、超时与结果未知分别处理，不自动换供应商，也不无限重试。

## 后续本地模型与实验

Ollama 和 llama.cpp server 保留为本地候选。切换本地后，继续使用同一技能目录、TaskView、PreparedPlan、审批和效果凭据；只替换推理适配与相关配置。具体模型、量化、上下文和最低硬件在该阶段实测决定。

当前对照固定云端供应商、模型配置、工具、权限与预算，记录运行时间、响应标识、usage、成本和客户端环境，并交错执行实验组。服务端模型漂移、硬件和负载无法完全控制，作为实验限制报告。后续本地复验再固定模型文件、量化、推理后端及硬件。云端收益不能直接作为小型本地模型收益的证据。
